# CLAUDE.md

## Repository Rules

- **Never use worktrees.** Work directly in the main working directory.
- **Never push to main without asking first** — this applies even in auto mode. Always confirm before pushing.
- **Do not create PRs.** This is a single-owner repo; commit/push directly (after confirmation) instead of opening pull requests.
- **Always ask when unsure.** Never assume intent, scope, or requirements — check first.

## Explaining Concepts

When asked to explain a concept, explain it in simple terms — aim for a college freshman level of explanation. Avoid unnecessary jargon, and define any technical terms that are used.
